# Security policy

## Reporting a vulnerability

Please report security problems privately, not in a public issue.

Use GitHub's private vulnerability reporting: open the repository's **Security** tab and choose **Report a vulnerability** (https://github.com/mrlikl/cfn2iam/security/advisories/new). The report is visible only to the maintainer.

Include what you found, how to reproduce it, and the version or commit affected. You can expect a first reply within a week.

## Supported versions

Only the latest release on PyPI is supported. Fixes are published as a new release.
